# Termux Fonts Installer
Um instalador simples de fontes para Termux. 
📥 1. **Instalação**
Dê permissão de armazenamento ao Termux  No Termux, execute:  ```termux-setup-storage```  Quando o Android solicitar permissão, toque em Permitir.  
2. **Copie o "install.sh" para o armazenamento compartilhado**
Baixe o arquivo "install.sh" do código-fonte deste repositório e coloque-o no armazenamento compartilhado do Android.  Por exemplo:  /storage/emulated/0/Download/  
3. **Copie o arquivo para o diretório do Termux**
No Termux:  ```cp /storage/emulated/0/Download/install.sh ~/```  

4. **Torne o arquivo executável**
```chmod +x ~/install.sh```
5. **Execute o instalador**
```~/install.sh```
🛠️ **Caso a execução direta não funcione**
Execute com:  ```sh ~/install.sh```
  📱 **Requisitos**
  - Termux - Permissão de armazenamento - "install.sh" - Suporte a scripts Shell ("sh")
